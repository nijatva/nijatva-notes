Nijatva Notes Source

Notes that stay on your phone.

Offline Markdown notes for Android, with an optional encrypted vault. No account, no sync, no ads, no analytics — and no network permission at all.

What it looks like

Plain Markdown in, plain Markdown out. The formatting bar sits above the keyboard, and Preview renders without leaving the note.

What it does

Small and single-purpose, the way the rest of the suite is built.

Markdown, not a database

Every note is a .md file in app-private storage. The index is rebuildable; a corrupt database costs you sorting, never your words.

An optional vault

Lock a note and it is encrypted at rest with AES-256-GCM. The key is derived from your passphrase, lives in memory only, and is dropped when the app goes to the background.

Notebooks and a real trash

Default and Quick note notebooks, plus your own. Deleted notes sit in Recently deleted for 30 days and can be restored.

Search, pins, favourites

Filter by notebook or favourites, search across titles and bodies, sort by edited, created or title.

Export when you ask

Send a note out as .md through the system file picker. Nothing leaves the app unless you choose a destination.

Follows the suite

Theme and accent come from nijatva-core's signature kit — System, Dark, Light or Black, with a Green, Saffron or Indigo accent.

Privacy, plainly

Not a policy you have to trust — properties you can check in the manifest.

  • No INTERNET permission. The app cannot open a socket, so it cannot phone home.
  • No storage permission. Files move only through the system picker, one file at a time.
  • No accounts, no ads, no analytics SDKs. There is no server to send anything to.
  • No Google Play Services. Runs on AOSP, on de-Googled ROMs and on BharOS.
The vault protects notes from someone holding your unlocked phone, and from casual file browsing. It does not defend against a determined attacker with root access to an unlocked device, and it is not a substitute for full-disk encryption. If you forget the passphrase, locked notes cannot be opened by anyone — including the developer.

Install

The APK is a debug-signed test build, not a Play Store release.

adb install nijatva-notes-0.3.0.apk
  • Or open the downloaded file on the phone and allow install from that app.
  • If an older Nijatva Notes is already installed, uninstall it first — each build is signed with a fresh debug key.
  • Requires Android 8.0 (API 26) or newer.

Status

Version 0.3.0 — a working prototype, not a finished app.

Working

  • Notes list with pins, favourites, search and sorting
  • Markdown editor with autosave, syntax toolbar and preview
  • Notebooks, Recently deleted, encrypted vault
  • Export to .md, shared Appearance and Developer screens

Not there yet

  • Import from a folder or zip
  • Grid view, attachments, biometric unlock
  • Full-text search index (FTS)
  • Compose UI — the current build uses framework Views
